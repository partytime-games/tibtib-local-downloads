# TIBTIB LOCAL

Téléchargements officiels de TIBTIB LOCAL pour Mac et Windows.

TIBTIB LOCAL permet d'animer des émissions KING TIME sur un réseau Wi-Fi local, même sans connexion Internet.

Les applications sont proposées aux clients disposant d'un compte TIBTIB autorisé.

**Plateformes :** Mac Apple Silicon, Mac Intel et Windows 64 bits.

**Installation :** suivre le guide d'installation fourni par TIBTIB.

Les applications ne sont pas encore signées commercialement. Des avertissements de sécurité peuvent apparaître lors de l'installation.
